# Accidion Identity Cloud Architecture Baseline

Proposed repository and MVP baseline; this document does not claim components are implemented. Accidion is a multi-tenant Identity Governance and Administration platform. MVP runtime: AWS ECS Fargate. Kubernetes is inactive until ADR approval. Messaging: SQS and EventBridge with transactional outbox. Data: Aurora PostgreSQL initially; PostgreSQL search initially. Valkey subject to approval. Workflow: Temporal Cloud. Authorization fails closed; tenant isolation is a security boundary. AI Copilot is disabled by default and limited to observe/reason/recommend if approved. Production changes are CI-controlled and human-approved. The six-month MVP plan governs delivery scope; do not create deployable services for deferred features.
